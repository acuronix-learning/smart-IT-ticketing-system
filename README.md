# Acuronix automation project

Generated by Acuronix from your manual test cases. Every locator was discovered and verified on the live application.

## Run locally
Windows: double-click `run.bat`. Mac/Linux: `sh run.sh`. Results are written to `results/results.xml`.

## Run in CI
Pipeline files for GitHub Actions, GitLab CI, Jenkins and Azure DevOps are included. Add two secrets/variables: `ACURONIX_URL` and `ACURONIX_TOKEN` (from your Acuronix project) so results appear on your dashboard. If your tests log in, also add `TF_USER` and `TF_PASSWORD`.
